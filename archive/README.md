# `archive/` — superseded code, kept for provenance

Nothing in this directory is part of the library. It is not built, not
tested by CI, not packaged, and not something to copy from. It exists so the
project's history can be traced rather than guessed at.

The library is [`include/lgpsf/`](../include/lgpsf/) (header-only C++17) plus
the Python bindings in [`bindings/`](../bindings/). Start at the
[README](../README.md) or [`docs/`](../docs/).
